# 🍽️ Tasty Bites — Restaurant Landing Page

A responsive, single-page restaurant website with a clean layout and interactive sections. Built with HTML, CSS and vanilla JavaScript, with no frameworks.

## ✨ Features

- **Responsive navbar** with a mobile hamburger menu and anchor-link navigation
- **Hero section** with a call-to-action button
- **About section** with the restaurant story and key stats
- **Menu section** with category filters (All, Starters, Mains, Desserts)
- **Image gallery** with a lightbox for enlarged view
- **Testimonials slider** with navigation dots
- **Contact form** with client-side validation and error messages for name, email and message
- **Back-to-top button** for easy navigation
- Fully responsive layout for desktop, tablet and mobile

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6)
